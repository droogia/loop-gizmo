Keys: 1–5 rec/dub/play track · Q W E R T stop track (hold 1 s = clear) · Space all start/stop · Z undo/redo · B rhythm start/stop · G tap tempo · ← → / ↑ ↓ menu cursor · Enter enter · Esc exit.
Knobs/faders: drag up/down or use the mouse wheel; double-click resets. Tracks: drop an audio file on a track strip to load it; TRACK opens track settings (reverse, one-shot, pan, import/export). The first recorded loop (or the rhythm, if running) sets the loop length; later tracks are synced to multiples of it.

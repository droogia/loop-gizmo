# Loop Gizmo — notes for future work

- Work directly on `main`; do not create branches.
- The manual exists in two languages: `MANUAL.md` (English) and `MANUAL.it.md` (Italian).
  Every change to one must be applied to the other in the same release, so that both stay aligned
  (same sections, same numbering, same version number). Panel/control names stay in English in both.
- The README is English only.
- When a release changes features, bump the version in `index.html` (title and header), README (version + history)
  and both manuals.
